### 群内分享文案（纯文本，可直接复制）

```
分享一个我自己做的 DSH 插件：dsh-save-chat

起因是我老在跟 AI 重复问一样的问题：一个报错之前解决过，过几天又碰到却找不到当时的回答；一个方案聊了半天，换个会话又得重新问一遍。

所以做了它：回复下面点一下红心，就把整轮问答（你的问题 + 完整回答）存成项目里的真实 Markdown 文件，之后能浏览、能复制引用，模型也能按需检索。

特点：
· 整轮问答一起存，不是单条回复
· 两层：会话收藏 + 个人知识库（~/.dsh/knowledge/年-月.md），按月分组
· 模型按需检索（search_knowledge / read_knowledge），不会自动塞进上下文
· 零依赖、无数据库、无遥测，就是普通 Markdown，能 grep、能进 git
· 桌面 App 和 dsh web 都能用

安装（web profile 是 web，桌面是 desktop）：
dsh plugin --profile web add dsh-save-chat

仓库（有 5 张截图）：https://github.com/xypang33-sketch/dsh-save-chat
有问题欢迎开 issue 或者直接问我
```

**配套图片**：把 `docs/screenshot-heart.png`（红心）、`docs/screenshot-panel.png`（面板）两张发群里就够；想更完整再加 `screenshot-knowledge.png`（知识库视图）。

## 3.3 即刻 / 小红书（偏故事、偏"我用它解决了什么"）

**标题建议**：`我给 AI 对话做了个"收藏夹"：一个红心，整轮问答存成 Markdown`

```
痛点开场：
我发现自己经常在跟 AI 重复问一样的问题。一个报错明明之前解决过，过几天又碰到，却找不到当时的回答；一个方案之前聊了半天，换个会话，又得再问一遍。来来回回，造了不少重复的轮子。

所以我做了个小插件 dsh-save-chat（给 DeepSeek Harness 用的）：
· 回复下面点一下红心 → 整轮问答（问题 + 完整回答）存成项目里的一个 .md 文件
· 侧栏有个收藏面板，按工作区 / 会话 / 条目分组，能搜、能读、能"在文件夹中显示"
· 你挑出来的那些可以提升进"个人知识库"，AI 之后能按需检索——注意是不问就不查，不会自动塞进上下文
· 全部是本机文件，零依赖、无数据库、无遥测

配图建议：红心图 + 面板图 + 知识库图（3 张，图上已经有标注，不用再解释）

结尾：仓库和安装方式放评论区/正文末尾
```

## 3.4 知乎 / V2EX（技术向长文）

写"**我为什么把 AI 对话存成 Markdown，而不是塞进数据库**"这类**有观点的技术文**，插件只是落脚点：

- 开场：重复提问的具体例子（越具体越好）
- 中间：三种做法的取舍——① 数据库/向量库 ② 自动记忆（如 ReMe） ③ 人工确认 + 纯 Markdown 文件。讲清各自的代价（可移植性、可控性、成本、隐私）
- 落地：dsh-save-chat 的实现要点（两层结构、按需检索、图片摘要让图片也能被检索、BM25 + 中文二元组、矛盾时以较晚者为准）
- 结尾：装上试试 + 反馈渠道
- 注意：**别写成纯广告**，V2EX/知乎对硬广很敏感；把"设计取舍"写足，插件链接放最后
